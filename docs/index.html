🧠 Smart UX API

AI-powered UI Automation for Java Web Applications

🚀 소개

Smart UX API는 Pure Java와 HTML5 기반의 기존 웹 애플리케이션에 인공지능 기반 화면 제어 기능을 쉽게 통합할 수 있도록 지원하는 오픈소스 도구입니다.

사용자가 전달하는 텍스트 기반 요청을 분석하여, 해당 요청을 수행하기 위해 어떤 UI 요소에 어떤 액션을 취해야 하는지를 AI가 판단하고 실행 가능한 액션 프로세스 정의서로 응답받아 화면을 자동 제어합니다.

GitHub 저장소 설치 가이드 API 문서 JavaDoc

✨ 주요 기능

🔌 손쉬운 통합

기존 Java 웹 애플리케이션에 JAR 파일만 추가하면 바로 사용 가능합니다.

🤖 AI 기반

OpenAI GPT, Google Gemini, Anthropic Claude 등 최신 AI 모델을 활용한 자연어 UI 제어.

🌐 범용성

순수 HTML5, React, Vue.js 등 모든 웹 프레임워크 지원.

⚡ 빠른 응답

최적화된 UI 정보 수집과 효율적인 AI 통신으로 빠른 실행 속도.

📝 상세한 문서

설치 가이드, API 레퍼런스, 예제 코드 등 풍부한 문서 제공.

🔒 보안

API Key는 서버에서만 관리되며 클라이언트에 노출되지 않습니다.

💻 Quick Start

1. 빌드

git clone https://github.com/kiunsea/smux-api.git cd smux-api/smart-ux-api/lib ./gradlew build

2. Java 코드

ResponsesChatRoom chatRoom = new ResponsesChatRoom(apiKey, "gpt-4"); chatRoom.addSystemMessage(uifDocument); ResponsesChatting chatting = chatRoom.createChatting(); String actionQueue = chatting.sendMessage(prompt, viewInfo);

3. JavaScript 클라이언트

const collector = new SmartUXCollector(); const viewInfo = collector.collectUIInfo(); const client = new SmartUXClient(); client.executeActionQueue(actionQueue);
